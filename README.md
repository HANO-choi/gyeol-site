# GYEOL — 한국 원목 가구 웹사이트

정적 HTML/CSS/JS 사이트. 메인 페이지는 `index-wonder.html` (레이아웃 B), `index.html`은 메인으로 이동만 합니다.

- `css/styles.css` — 모노크롬 디자인 시스템 (색·서체·버튼 토큰)
- `css/wonder.css` — 레이아웃 B 섹션 스타일
- `css/motion.css`, `js/motion.js` — 공지 띠, 스크롤 등장, 패럴랙스
- `js/wonder.js` — 헤더 숨김, 히어로 슬라이드쇼, 제품 탭, 가로 스크롤
- 디자인 시스템 (Figma): https://www.figma.com/design/YzPWPAim3nGNrrjMa86dBt
